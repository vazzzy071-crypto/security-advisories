## Coordinated Vulnerability Disclosure (CVD) Policy

We strictly adhere to responsible disclosure principles:
- **Vendor Outreach**: We notify vendor security teams or accredited CNAs with comprehensive technical details, reproducible PoCs, and remediation guidance.
- **Grace Period**: We respect standard 90–120 day disclosure timelines to allow maintainers to remediate vulnerabilities before public disclosure.
- **Archived / Abandoned Projects**: For projects where the repository is archived or unmaintained, public advisories are coordinated directly with CNAs (e.g. VulnCheck) to serve as public references for CVE assignment and ecosystem awareness.
